# NoCode_Macro

> Create automation macros for Windows **without writing any code**

## About

NoCode_Macro is a lightweight, modern and 100% offline Windows application. It allows users to build, edit and execute macros through an intuitive drag & drop interface without writing any code. No cloud syncing, no data tracking, no ads, no random popups just pure local performance.

## Key features

- **Intuitive Interface:** Easily grab action blocks (**Carts**) and glue them together to form a sequence (**Train**)
- **Silent:** No ads, no popup, no account, no icon in taskbar and no notifications.
- **Key Recorder:** Record any **keystrokes** or **mouse clicks & coordinates** in real time and automatically turns them into a fully editable train.
- **Export/Import Trains:** Users can **import or export Trains** to share their macros with other users.
- **Easy Organisation:** Create folders to easily sort **Trains**
- **100% offline:** 100% local app that doesn't need any internet to run **Trains**
- **Attribute Hotkeys:** Trigger any **Train** at anytime by clicking an attributed hotkey or a hotkey combination

## Tech Stack

This project follows a strict separation of concerns for maximum performance and security:

- **Frontend (UI):** `React` + `TypeScript` — Handles the visual Canvas, Drag & Drop mechanics, and user configurations.
- **Backend (Core):** `Rust` - Handles low-level Windows OS interactions, simulates events, and ensures memory-safe execution.
